# 🧪 软件测试智能工作台

> 一个面向测试工程师的一站式效率工具，覆盖 **需求分析 → 用例设计 → 自动化脚本 → Bug 管理 → 测试报告** 全流程，并集成 AI 大模型能力辅助测试工作。

## 🚀 在线演示

**访问地址：https://sun-zhenaa.github.io/ai-test-workbench/**

> 纯前端应用，打开即用，无需安装。数据保存在浏览器本地（localStorage）。
>
> 提示：Gitee 已下线个人免费 Pages 服务，因此演示使用 CloudStudio 部署。

## 📦 功能模块

| 模块 | 功能说明 |
|------|---------|
| 📋 需求文档分析 | 上传/粘贴需求文档（支持 txt/md/csv/xlsx/docx），AI 深度解析提取功能点，自动生成需求大纲 |
| 🧪 测试用例生成 | 输入功能点，AI 按等价类/边界值/场景法生成标准测试用例，支持多种模板 |
| 📊 用例分析 | AI 对比需求与用例，分析覆盖率缺口，给出改进建议 |
| 🐍 Python 脚本生成 | 根据接口信息生成 Python + pytest 自动化脚本，内置质量检查、规则修复、AI 优化、版本 diff 对比 |
| 🐛 Bug 管理 | Bug 登记、状态流转、严重程度统计、CSV 导出 |
| 🎲 测试数据生成 | 内置 GB2260 地址码、银行 BIN、运营商号段数据，一键生成姓名/身份证/手机号/银行卡等 9 类测试数据 |
| 📝 每日任务 & 测试报告 | 任务打卡、周报自动生成 |
| 📚 面试刷题 | 内置测试面试题库，卡片/列表双模式、错题本、掌握度标记 |
| 🛠️ 工具技能 & 学习计划 | 测试工具速查、Python/pytest 学习路线 |

## 💡 技术特点

- **单文件架构**：HTML + CSS + JS 全部内联，一个 index.html 即完整应用，零依赖部署
- **AI 集成**：OpenAI 兼容 API 格式，支持配置任意大模型服务（密钥仅存本地，不上传）
- **多格式文档解析**：SheetJS 解析 Excel、mammoth.js 解析 Word，动态按需加载
- **数据持久化**：localStorage 分模块存储，支持导出/导入/回收站
- **响应式设计**：适配桌面与移动端，支持深色模式

## 🖥️ 本地运行

无需构建，任选一种方式：

1. 直接双击 `index.html` 用浏览器打开
2. 或启动本地服务：`python -m http.server 8080`，访问 `http://localhost:8080`

## 🔧 使用 AI 功能

进入「设置 → AI 配置」，填入任意 OpenAI 兼容接口的地址和 API Key 即可（如 DeepSeek、通义千问、Kimi 等）。密钥只保存在你的浏览器本地。
